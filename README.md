# 🌾 ระบบบริหารวิสาหกิจชุมชน

ระบบบริหารจัดการวิสาหกิจชุมชนแบบครบวงจร พัฒนาด้วย HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้ง server ใดๆ

## ✨ ฟีเจอร์

- 👥 **ทะเบียนสมาชิก** — เพิ่ม/ลบสมาชิก ระบุบทบาท เช่น ประธาน กรรมการ เหรัญญิก
- 💰 **บัญชีรายรับ-รายจ่าย** — บันทึกรายการพร้อมหมวดหมู่และวันที่
- 📦 **คลังสินค้า** — จัดการสินค้า แจ้งเตือนสินค้าใกล้หมด
- 📊 **รายงานสรุปผล** — ดูภาพรวมกำไร/ขาดทุน
- 📥 **ส่งออก Excel** — รายงานครบ 4 ชีท (สรุป / บัญชี / สมาชิก / สินค้า)
- 📄 **ส่งออก PDF** — รายงานมืออาชีพ พร้อมตาราง KPI และหัวท้ายหน้า

## 🚀 วิธีใช้งาน

### เปิดใช้งานตรง (ไม่ต้อง server)
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

### รันผ่าน GitHub Pages
1. Fork repository นี้
2. ไปที่ **Settings → Pages**
3. เลือก Source: `main` branch, folder `/root`
4. กด Save — จะได้ URL เช่น `https://username.github.io/visahakij/`

### รันผ่าน localhost
```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
แล้วเปิด http://localhost:8000

## 📁 โครงสร้างไฟล์

```
visahakij/
└── index.html    # ไฟล์เดียว ครบทุกอย่าง
```

## 📊 รายงาน Excel (4 ชีท)

| ชีท | เนื้อหา |
|-----|---------|
| สรุปผล | KPI หลัก รายรับ รายจ่าย กำไร |
| บัญชีรายรับ-จ่าย | รายการทุกรายการพร้อมหมวดหมู่ |
| ทะเบียนสมาชิก | ข้อมูลสมาชิกทั้งหมด |
| คลังสินค้า | สินค้าพร้อมมูลค่าคงคลัง |

## 📄 รายงาน PDF

- หัวหน้ารายงานพร้อมชื่อกลุ่มและวันที่
- กล่อง KPI แสดงยอดรายรับ รายจ่าย กำไร/ขาดทุน
- ตารางรายการบัญชี
- ทะเบียนสมาชิก
- รายการสินค้าและมูลค่าคงคลัง
- เลขหน้าและ footer ทุกหน้า

## 🛠️ เทคโนโลยีที่ใช้

- HTML5 / CSS3 / JavaScript (Vanilla)
- [SheetJS (xlsx)](https://sheetjs.com/) — สร้างไฟล์ Excel
- [jsPDF](https://github.com/parallax/jsPDF) + [AutoTable](https://github.com/simonbengtsson/jsPDF-AutoTable) — สร้างไฟล์ PDF
- [Sarabun Font](https://fonts.google.com/specimen/Sarabun) — ฟอนต์ภาษาไทย

> **หมายเหตุ**: ข้อมูลเก็บใน memory เท่านั้น เมื่อรีเฟรชหน้าจะหายไป หากต้องการเก็บข้อมูลถาวรสามารถเพิ่ม localStorage หรือเชื่อมต่อ backend ได้
